# V2：KV Head 表示结构与 Attention 行为——计划与结果

状态：100 条 V2 表示采集、谱/CKA 数值包及问题 A～D 的跨输入分析均已完成并核验。联合研究结论见第 12 节，分项方法与结果见第 11.6～11.9 节。Head 表示画像、RoPE 响应、具体 Head 对 CKA 及与 Attention 的主要关联得到扩展支持，但输入残差关联较弱且依赖条件；压缩、重建干预尚未开展。本文作为该阶段唯一报告，后续继续补充实际方法、结果和限制。背景及已完成工作见[研究总览](研究总览.md)。

## 1. 核心假设与三个研究层次

**核心假设：不同 KV Head 在 Attention 访问行为上表现出的稳定差异，是否对应其 K/V 数值分布、特征能量分布、有效秩及跨 Head 表示相关性上的差异？**

B1 已观察到 Head 时间稳定性差异及跨条件相对排序一致性。B2 及其探索性留出分析发现，Prefill CV 与 Decode 稳定性相关，但在当前同条件、简单线性模型下，加入当前 CV 未见超出 Head 历史稳定性基线的稳定增量。这为进一步研究 Head 表示结构提供动机，尚不能证明差异来自 K/V 的某种结构。

首轮限定为六条输入的 Pilot，依次回答三个问题：

| 层次 | 核心问题 | 主要观测 |
|---|---|---|
| 单 Head 表示分布 | 不同 Head 的表示结构是否存在差异？ | K/V 数值范围、向量范数、特征能量、协方差谱和有效秩 |
| 跨 Head 表示关系 | 不同 Head 是否具有共享的潜在表示特征？ | 同一批 Token 上的线性 CKA 及位置置换参照 |
| Attention 与 KV 表示的联系 | Attention 行为不同的 Head，其表示是否也有对应差异？ | 表示指标、CKA 与 B1 Page RCO 对齐 |

Pilot 用于确认采集正确性、成本及探索性现象，不承担独立新输入预测、因果检验或压缩收益验证。保留连续 Head 指标，不预先划分固定的 Stable/Unstable 类别。

参考来源：

- [FlexiCache](https://arxiv.org/abs/2511.00868)：Head 的 Decode 时间稳定性差异；V2 沿用 B1 的真实 Attention Page Mass/RCO，不复现其 Page 管理系统。
- [CateKV](https://arxiv.org/abs/2608.30295)：Prefill 跨 Query 特征；已有 CV 作为补充参照，不新增参数搜索。
- [KV Cache Transform Coding（KVTC）](https://arxiv.org/abs/2511.01815)：K/V 特征冗余、跨 Head 正交对齐和 RoPE 影响。本文的逐 Head 谱与 CKA 不等同于论文的整体 PCA 或 Procrustes 实验，不将相似现象写成其压缩效果复现。

## 2. 样本与执行范围

复用固定输入、模型快照、BF16、SDPA、Batch=1 以及完整无压缩 Cache。模型为 Llama-3.1-8B-Instruct：32 层、8 个物理 KV Head、每 Head 128 维；不将 GQA 的 32 个 Query Head 当作 32 个独立 KV Head。

| 条件 | 样本 | 实际 Prompt Token 数 T | B1 Decode 观测数 |
|---|---|---:|---:|
| RULER 8K | `ruler_8k_001` | 8072 | 6 |
| RULER 32K | `ruler_32k_001` | 32650 | 6 |
| GovReport 8K | `govreport_8k_001` | 7205 | 712 |
| GovReport 16K | `govreport_16k_001` | 15594 | 1023 |
| PG19 8K | `pg19_001_8k` | 8192 | 461 |
| PG19 32K | `pg19_001_32k` | 32768 | 940 |

PG19 为同一续写锚点的一对长度，不能作为两个独立来源。已有重复输出限制保留。六条输入均来自已研究的数据，Pilot 只作描述和方法验证，不做正式泛化推断。

先完整 Prefill，再回放 B1 已有生成 Token。四条长文本只回放前 256 个 Decode Forward，RULER 回放其全部 6 个 Forward；逐 Forward 核对 Top-1 与 B1 对应生成 Token，不重新选择生成分支。回放 N 次需要 B1 的前 N+1 个生成 ID：Prefill 预测 `ids[0]`，Decode 第 s 次消费 `ids[s]`、预测 `ids[s+1]`。因此长文本读取前 257 个 ID，RULER 读取前 7 个；不足时明确报错，不自动缩短协议。B1 主 RCO 来自原有完整轨迹，V2 截断回放只服务于表示采集和一致性检查。

## 3. 观测位置及只读约束

### 3.1 已核对的模型执行路径

已只读检查本地、远端 Transformers 5.2.0 的 `LlamaAttention.forward()`：

```text
Attention 模块入口：取得 layer、forward、cache_position
    ↓
k_proj(hidden_states) → reshape/transpose → K_pre
    ↓
apply_rotary_pos_emb(query, K_pre, cos, sin) → 新 Token 的 K_post
    ↓
Cache.update(K_post, V, layer_idx) → 当前完整 Cache 的 K_post/V
    ↓
Attention Function(module, Q, K_post, V, ...)
```

`v_proj` 也在 RoPE 之前执行；当前 Llama 不对 V 应用 RoPE。`AttentionProbe` 的 Attention 回调已扩展为公开实际 Q/K/V，其中 K/V 来自 Cache 更新后；早期 K 通过独立的可选投影回调公开。

### 3.2 只读观测方式

- 在实际 `k_proj` 模块上安装只读输出 Hook，从原模型这一次投影的输出抽取指定位置，得到 `K_pre`。输出原形状为 `[1,q_len,8×128]`，按模型实际 reshape 顺序恢复 Head 轴。Hook 返回 `None`，不替换输出。
- 复用 Attention 模块入口取得的 `cache_position`，将当前投影行与绝对 Token 位置关联；不能仅按当前序列长度推测位置。Prefill 与 Decode 的同层同 Forward 记录必须配对。
- 在现有 Attention Function 边界读取实际传入的 Cache 更新后 `K_post/V`。对新 Token，以绝对位置定位到 Cache 对应行；Prompt 全量统计仅在 Prefill 执行。
- 不再次调用 `k_proj`、不重算或逆变换 RoPE 来生产 `K_pre`、不改写 Attention 输入或 Cache。只把必要的统计和抽样向量转到 CPU，不跨层持有完整 GPU K/V 引用。

改动位于 `experiments/head_analysis/` 的 runtime、Collector、运行组装和离线分析模块，复用现有加载、回放与读写函数，未修改安装的 Transformers 源码。

`runtime/attention_probe.py` 的 `on_key_projection` 提供 `KeyProjectionContext.key_pre` 和绝对 `token_positions`；`on_attention` 提供既有 Context 的 `key` 与新增 `value`。两个回调按样本、Layer、Forward 和位置关联，投影 Hook 仅在启用早期回调时安装。Probe 不保留 K_pre。

`collectors/kv_representation.py` 在同步回调中抽样、分块计算 CPU 统计，并把逐层记录交给 `storage/kv_representation.py`。Collector 不持有完整 GPU K/V；Decode 期间仅保留 Prefill 抽样 K_post/V 的 CPU 副本，以检查历史 Prefix。Writer 复用现有 NPZ/JSON 原子写入，完整收齐所配置的全部 Layer/检查点且 Prefix 检查通过后，才标记样本完成。

`runners/kv_representation_runner.py` 复用 B2 的固定输入和 B1 轨迹读取、执行契约检查、`teacher_forced_replay` 及共用模型加载/计时。直接使用冻结 `input_ids`，不重新分词；外层安装 V2 Probe，逐层落盘，全部 Top-1 核对通过后才调用 Writer 完成。保存来源样本、实际回放 ID、检查点和必要运行信息。异常时停止后续样本、保留部分输出并记录失败；不覆盖既有目录，也不增加 Git 状态检查或 Hash 清单。

V2 的统计和 NPZ 写入发生在同步回调内，因此记录的 Forward/回放耗时包含这些开销，不沿用 B1/B2“排除写盘”的解释。GPU 路径记录峰值显存；六条 Pilot 的 8K/16K/32K 实测汇总见第 10 节。

### 3.3 RoPE 与位置正确性

当前目标快照配置使用 `rope_type=llama3`，对应当前 Transformers 实现的幅值因子为 1。理论上单 Token 的旋转保持范数：

$$\|K_{\mathrm{pre},i}\|_2=\|K_{\mathrm{post},i}\|_2.$$

报告抽样 Token 的前后绝对范数差及相对差；近零向量以绝对差解读。允许 BF16 舍入误差，具体验收容差先由小模型 FP32/BF16 直接对照确定，再固定用于真实模型，不在遇到失败后自动放宽。此结论限定于该 RoPE 配置，不能无条件外推到带额外幅值缩放的变体。

范数一致不是充分证明：仍需检查绝对位置、Head 顺序、Hook 调用次数，以及 Attention 输入的新 Token 与更新后 Cache 对应位置的一致性。不同 Token 也可能范数接近，不能仅凭范数通过验收。

逐位复算 RoPE 时需复用实际初始化路径：当前 Runner 先在 CPU 构造 `inv_freq`，再随模型移至 GPU，复核也应如此。直接在 GPU 重建频率或改在 CPU 执行旋转可能产生舍入差异，不能据此判定采集错误。

## 4. 全量统计与抽样原始向量

令完整 Prompt 为 `[0,T)`，中段为 `[64,T−64)`。所有层及 Head 使用相同位置定义。

| 表示 | 完整 Prompt | 中段候选区 | 512 个抽样位置 |
|---|---|---|---|
| K_post | 全量 Token 紧凑统计 | 全量 Token 紧凑统计 | 保存原始向量 |
| V | 全量 Token 紧凑统计 | 全量 Token 紧凑统计 | 保存原始向量 |
| K_pre | 不做全量统计 | 不做全量统计 | 保存原始向量 |

512 个位置由最前 32、最后 32 和中段均匀确定性选取的 448 个位置组成。中段第 j 个抽样位置为 `64+floor((j+0.5)×(T−128)/448)`，`j=0,…,447`；保持唯一、排序并记录绝对位置及区域标签。不得根据观察到的 RCO、CV 或表示结果选取位置。

原始抽样数组每种表示的形状为 `[L=32,Hkv=8,S=512,D=128]`，保留模型原始 BF16 数值。离线基于完全相同的 512 个位置，及其中相同的 448 个中段位置，分别计算 K_pre、K_post、V 的统计和谱。

**K_pre 与 K_post 的结构比较必须使用同一抽样范围。** 完整 Prompt K_post 与抽样 K_pre 的指标分开放置、独立标注，不能将其差异直接归因于 RoPE。抽样 K_post/V 与全量 K_post/V 的差异只用于检查抽样代表性。

### 4.1 协方差与精确 Norm 分位数

对任一范围内的 Token 矩阵 $X\in\mathbb R^{N\times128}$，保存 N、均值向量 μ、总体协方差 C，以及 Norm 统计：

$$\mu=\frac1N\sum_iX_i,\qquad C=\frac1N\sum_i(X_i-\mu)^\top(X_i-\mu).$$

总体协方差采用 `ddof=0`。优先以 FP64 分块 Chan/Welford 累积计数、均值和中心化二阶矩，最终保存 FP32 协方差。小模型用直接中心化 FP64 计算作参考，检查谱对保存精度的敏感性。禁止在 BF16 下直接累积 `XᵀX−Nμᵀμ`。

全量 K_post/V 的每个 Token 范数在 FP32 计算后转到 CPU，按 `linear` 方法计算精确 P10、P50、P90，不用分块分位数的平均值代替。建议保留这些 FP32 标量范数，形状每种表示为 `[L,Hkv,T]`；中段范围通过位置切片得到，不再保存重复的中段范数数组。抽样 K_pre 范数从保留的原始向量重算。

现实现按 Layer 落盘，单层范数为 `[Hkv,T]`；均值、协方差等按 `prompt/middle` 两个范围保存，另有特征能量和元素范围。采样原始向量为 `[Hkv,512,D]`。BF16 以 uint16 原始位写入 NPZ，元数据记录原始 dtype，读取时恢复 BF16；不是整数数值转换，也不隐式扩大为 FP32。两个 K/V 全量范围都不新增 K_pre 统计。

## 5. 三层指标与解释

### 5.1 单 Head 表示分布

每个样本、Layer、KV Head、表示和范围独立计算，保留范围及 N。

- 数值范围：元素最小值、最大值、最大绝对值；Token L2 Norm 的均值、P10/P50/P90 和最大值。它们反映数值大小，不直接等于 Token 的 Attention 重要性。
- 原始坐标特征能量：$e_j=N^{-1}\sum_iX_{ij}^2$，可由 $C_{jj}+\mu_j^2$ 得到。保存 128 维向量及其归一化分布。此指标依赖坐标系且包含均值能量，不能称为 PCA 方差。
- 中心化协方差谱：以对称化 C 的降序特征值 λ 定义 $E_k=\sum_{j\leq k}\lambda_j/\sum_j\lambda_j$，报告 `k=8/16/32/64`，以及达到 90% 方差的最小维数 r90。
- 有效秩：$p_j=\lambda_j/\sum_m\lambda_m$，$r_{eff}=\exp(-\sum_{p_j>0}p_j\log p_j)$。总方差为零时标记无效；保存完整谱以便改变解释比例阈值，无需重跑模型。

协方差的可忽略负特征值须有记录其大小的数值容差，再截为零；本轮实现使用 `D×eps(FP32)×max|λ|`，保存截断前最小特征值和该容差。明显负特征值报错，不能静默修补。Norm 不变不要求跨 Token 协方差谱不变，因为不同位置经历不同旋转。

### 5.2 跨 Head 表示关系

默认对全部 32 层、每层 8 个物理 KV Head 的 28 个无序组合计算 CKA；K_pre、K_post、V 分开。主范围固定为相同的 448 个中段抽样位置，避免混入首尾区域权重；全量统计不用于构造此 CKA。

对各自按特征中心化的 $X_c,Y_c\in\mathbb R^{448\times128}$：

$$CKA(X,Y)=\frac{\|X_c^\top Y_c\|_F^2}{\|X_c^\top X_c\|_F\,\|Y_c^\top Y_c\|_F}.$$

分母为零时标记无效，保留有效对数。该指标描述对齐 Token 的线性表示结构相似性。

位置置换参照固定为 **50 次**，seed=20261111。每次仅打乱一个 Head 的 Token 行，计算 `CKA(X_c,P_b Y_c)`；同时打乱两侧不会破坏对应关系，不能作为参照。同一样本的 Head 对和三种表示复用同一套置换索引，保持范围和 N 不变。保存每次结果、均值、P5/P95，另报告 `CKA−置换均值`。

全部六条共有 `6×32×28×3=16,128` 个观察值、806,400 个置换参照值。使用缓存的 Token Gram 矩阵及按层分批计算控制成本；先离线计时，不因计算较慢而事后挑选 Layer。确需改变次数或范围时，应在结果解读前明确修订方案；50 次不用于宣称正式尾部显著性。

置换参照破坏了共同输入内容与位置的对应关系，不能将“高于参照”解释为已排除了共享输入的影响。CKA 还受维度、N 和 Token 选择影响；不跨不同 N 直接作同口径比较。高 CKA 不证明可共享或合并 Cache，也不等于低秩或压缩后的模型质量可保持。

### 5.3 Attention 与 KV 表示的联系

使用已有样本的 B1 `prompt_only Page RCO、k=32、Δ=32` 作为主对照，保留未截断的 `rco_raw_mean`、有效 Step 对数及 `(sample_id,layer_id,kv_head)` 坐标。四条长文本适用，RULER 不参与该长间隔关系，可另列 `all_visible Token RCO、k=32、Δ=1` 的短轨迹描述。

主要关系限定为：

1. 完整中段 K_post、V 的 `r_eff / E16` 与 Page RCO 的关系。逐样本先在每层内减去该层 Head 均值，再对 256 个固定 Head 坐标计算 Spearman。
2. 每个 Head 与同层其余 7 个 Head 的平均 CKA 与该 Head Page RCO 的关系；观测 CKA 及其超出置换均值的部分分别保留。无效对不补零并记录实际邻居数，以同样 Layer 去中心化口径作描述。

K_pre 与 K_post 的关联差异仅用相同的 448 个中段抽样位置作敏感性比较。原始坐标能量和 r90 用于解释，不自动展开更多参数搜索。CKA 的 28 个 Head 对不能直接当成 28 个独立 Head 样本；邻居平均也不构成新的独立样本。

本轮以每条输入的结果及差异为主，不把 Layer、Head 或 Head 对当作独立实验样本。不在六条数据上训练预测器或给出正式总体显著性结论；PG19 配对不增加独立样本数。使用当前样本完整轨迹 RCO 是事后结构关联分析，不是 Prefill 预测实验。

## 6. Decode：只检查新增 Token 与历史一致性

第一轮采用“目的 A”：每个检查点只保存其对应的一个新 Token，不研究 Decode 整体分布，也不保存累计生成窗口。

| 样本范围 | 消费的生成 Token | B1 Decode Step s | Cache 绝对位置 | 每个检查点新增保存 |
|---|---|---:|---:|---|
| 四条长文本 | `generated_ids[31]` | 31 | T+31 | K_post/V 各 `[L,Hkv,128]` |
| 四条长文本 | `generated_ids[255]` | 255 | T+255 | K_post/V 各 `[L,Hkv,128]` |
| 两条 RULER | `generated_ids[5]` | 5 | T+5 | K_post/V 各 `[L,Hkv,128]` |

以上共 10 个新 Token 的全层 K/V。它们用于补充数值检查，不能形成 Decode K/V 总体分布或有效秩结论。

各检查点另读取 Prefill 保存的 512 个 K_post/V 位置，与当前 Cache 对应行作一致性比较，保存误差摘要，不重复写入整套历史向量。当前标准无压缩 Llama Cache 对既有位置应保持一致；若发现变化，先定位执行/位置/配置原因，不将其当成表示演化。Prefix 检查须记录对比数值是否完全一致及最大绝对差。

## 7. 验证与推进顺序

| 步骤 | 必须确认的内容 |
|---|---|
| 小模型采集 | 每层每 Forward 的真实 k_proj 只执行一次；Hook 不替换输出；K_pre 位置和 Head 顺序正确；新增 K_post/V 与 Cache 对应行一致 |
| 数值参考 | FP64 直接中心化参考与分块统计一致；Norm 分位数与 CPU 全量标量计算一致；已知低秩/常量数据的谱、有效秩和无效标记正确 |
| RoPE 与 CKA | 同位置前后范数误差在验证容差内；CKA 自比较为 1，正交变换与整体缩放不改变其值；置换参照可重现，但不要求每个 Head 对的观察值一定高于置换 |
| 推理与清理 | 无采集/带采集 Token、Top-1 和小模型 Logits 对照；异常后 Hook 释放；不保留跨层完整 GPU Tensor |
| 单条 8K | 先运行 GovReport 8K，实测时间、GPU 峰值及落盘大小；检查两个 Decode 新位置和历史 Prefix |
| 六条 Pilot | 再验证 16K/32K 与 RULER 短轨迹，对齐旧样本及 B1 指标，覆盖全部 32 层 |
| 离线判断 | 按三个研究层次解释结果，记录不支持假设的结果，再决定是否扩大样本 |

真实模型 Pilot 仍需依据当时 GPU 和磁盘资源安排，不把磁盘估算当成运行时间或显存承诺。

## 8. 空间预算

以下按 BF16 原始向量、FP32 落盘协方差/Norm、32 层×8 KV Head×128 维估算，均为未计压缩的逻辑字节。六条实际 Prompt 合计 104,481 Token。

| 内容 | 计算口径 | 空间 |
|---|---|---:|
| Prefill 抽样原始向量 | `6×3(K_pre/K_post/V)×32×8×512×128×2` 字节 | 576 MiB |
| 全 Prompt/中段协方差 | `6×2(K_post/V)×2(scope)×32×8×128×128×4` 字节 | 384 MiB |
| 全 Prompt Token Norm | `104481×2×32×8×4` 字节，中段复用切片 | 约 204 MiB |
| Decode 新 Token | `10×2(K_post/V)×32×8×128×2` 字节 | **1.25 MiB** |
| 离线谱、CKA 和其 50 次参照、均值、索引 | 紧凑数组，抽样协方差可从原始向量重算，不重复持久化 | 预留 10～30 MiB |

主要文件约 **1.15～1.2 GiB**，建议预留 **2～4 GiB** 作为落盘和临时空间预算。若验证后必须将全部协方差保存为 FP64，增加约 384 MiB。具体格式不得意外把原始 BF16 扩为 FP32 后仍引用本预算。

此前 Decode 约 146 MiB 的估算对应累计生成窗口；本方案只保存上述 10 个 Token，已改为 1.25 MiB。运行中的完整 Cache、模型权重、统计工作区和 CPU/GPU 峰值内存另计。All-layer CKA 增加离线计算成本，输出存储仍较小。

2026-11-11 只读检查中，项目所在共享 NFS 的 df 显示总量 163T、已用 153T、可用约 2.1T、使用率 99%；项目 `data/` 约 17G，其中 runs 约 15G。此为时间点记录，启动前需重新确认，不因本方案预算小而认为共享空间可长期保证。

使用原 B1 完整 Decode 轨迹的 `prompt_only Page RCO,k=32,Δ=32,rco_raw_mean`。每条输入先分别去除两侧的 Layer 均值，再在 256 个物理 Head 坐标上计算 Spearman；不把 Head 当作独立输入。下表为主要关系，V CKA 是同层有效邻居的平均观察 CKA。

| 条件 | K_post 有效秩 | K_post E16 | V 有效秩 | V E16 | V CKA |
|---|---:|---:|---:|---:|---:|
| GovReport 8K | +0.138 | −0.244 | −0.176 | +0.160 | −0.222 |
| GovReport 16K | +0.150 | −0.242 | −0.187 | +0.186 | −0.316 |
| PG19 8K | +0.100 | −0.131 | −0.186 | +0.194 | −0.299 |
| PG19 32K | +0.083 | −0.104 | −0.147 | +0.144 | −0.354 |

四条长期样本每个 Head 的有效 Step 对分别为 **680、991、429、908**。两条 RULER 只有 6 次 Decode，不参加该关系；只保留按 4 个 Query Head 聚合到物理 KV Head 的短间隔 Token RCO 描述。

### 10.5 固定 Head 统计画像与输入变化

仅使用上述六条完成数值包，分别分析 16 项已有的有效秩、E16、平均 Norm、Head 邻居平均 CKA/超额 CKA 和 RoPE 秩比；不重算谱或 CKA，不新增采集，也不把不同量纲的特征合成一个总分。

对每项 `X[输入,Layer,KV Head]`，在共同有效坐标上分解为 `X=层均值+输入层平移+固定Head差异+输入×Head响应`：层均值是跨输入及 Head 的均值；输入层平移是该输入整层 Head 均值的偏移；固定 Head 差异是该 Head 跨输入均值相对层均值的偏移；其余为响应项，包含内容、任务、长度及抽样变化，不能单独解释为噪声。三项平方和之和等于去除层均值后的总平方和，份额是描述性占比，不是无偏方差分量、ICC 或因果解释率。

同时报告去除每个输入整层均值后的相对固定份额 `SS_Head/(SS_Head+SS_响应)`，以及跨输入的层均值去除后 Spearman。验证时用其他来源组的相对 Head 均值重现当前输入，PG19 两个长度同时从训练均值中排除。`skill=1-SSE_预测/SSE_所有Head相同`，负值保留；目标已使用当前输入自身的层均值，因此只评价相对画像复用，不是绝对特征预测或独立新输入泛化。

下表为全部六条的结果，跨数据集相关取 12 对输入的中位数，不将这些比较视为独立样本。

| 特征 | 固定 Head 份额 | 去输入层平移后的固定份额 | 跨数据集 Spearman | 留来源组 skill |
|---|---:|---:|---:|---:|
| 完整中段 K_post 有效秩 | 91.99% | 95.38% | 0.936 | 0.935 |
| 完整中段 V 有效秩 | 79.06% | 91.04% | 0.893 | 0.843 |
| 完整中段 V E16 | 79.63% | 92.10% | 0.899 | 0.864 |
| V 平均邻居 CKA | 82.98% | 96.01% | 0.944 | 0.931 |
| V 平均邻居超额 CKA | 75.50% | 96.06% | 0.936 | 0.934 |
| 同 448 位置 RoPE 后/前秩比 | 96.64% | 98.04% | 0.904 | 0.969 |

**相对 Head 画像主要保持在固定坐标上，但绝对数值仍随输入改变。** 全部 16 项各自的固定份额为 75.5%～97.3%；去输入层平移后为 89.7%～98.9%。K_post/V 的平均 Norm 尤其稳定，固定份额约 96.9%/97.3%。同一 Head 跨输入的 RMS 波动相对 Head 间 RMS 差异，K_post 有效秩约为 29.5%，V 约为 51.5%。V 有效秩的整层输入平移仍占 13.2%，超额 CKA 的整层平移占 21.4%，不能说同一 Head 的数值基本不变。

该结论也保留逐层差异。K_post/V 有效秩的逐层相对固定份额中位数约 95.9%/90.7%，逐层输入对排序相关中位数约 0.929/0.905；RoPE 秩比的逐层相对固定份额中位数约 92.8%，低于聚合的 98.0%。聚合平方和更重视 Head 差异幅度大的层；V 有效秩最弱层的相对固定份额约 64.9%，因此不将总体结论写成每一层、每一个 Head 都固定。

敏感性分析使用仅四条长文本，以及 PG19 分别仅保留 8K/32K 代表的两套五条子集。V 有效秩的固定份额仍为 77.4%～82.2%、相对固定份额约 91.4%～91.8%，V CKA 与 RoPE 响应的主要判断也保持。按来源成组留出的相对画像误差相对统一 Head 基线明显降低，但少样本留出只是本批数据的复用检查。

新增分析及相关模块共 18 项 CPU 测试通过；本地分析约 8 秒、输出约 1.94 MiB。独立由原值均值重算全部 64 个特征/子集分解及 320 个留出案例，结果与发布数据相容；相关系数和留出预测重算一致。入口为 `scripts/analyze_head_identity.py`，新结果位于 `data/analysis/v2_head_identity_6_20261111_v1/`，原六条数值包保持不变。

这里支持的是**固定 Head 的统计属性**。秩稳定不证明 PCA 方向或变换基固定，平均邻居 CKA 稳定不证明具体 Head 配对关系固定，也没有检验固定属性之外的输入变化能否进一步解释 RCO。现阶段可把固定 Head 画像视为后续标定或候选预算的先验，尚不能直接确定压缩比例。

### 10.6 当前结论与结果位置

本轮支持三个描述性结论：Head 的 K/V 分布和表示复杂度存在差异，且许多统计画像在六条输入间保持；相同 Token 上跨 Head 激活结构相关；这些结构与 Attention 稳定性只有部分、且 Key/Value 方向不同的联系。**不支持“稳定 Head 统一更低秩或更易压缩”这一简单规则。** 尚未验证因果性、新输入泛化、KV 共享、压缩质量、显存节省或加速。

原始采集分别位于 `data/runs/v2_kv_govreport_8k_001_20261111_v1/`、`data/runs/v2_kv_pilot_remaining5_20261111_v1/`；保留，不覆盖。采集核验摘要为 `data/analysis/v2_kv_pilot_6_20261111_v1.validation.json`。完成数值包为 `data/analysis/v2_kv_pilot_6_20261111_v1/`，包含来源和指标定义、实际置换、逐样本谱/CKA/原始 RCO 与有效数；本地只同步该紧凑数值包及摘要，未同步原始 K/V Trace。

固定 Head 统计画像能否转化为可复用的子空间或候选预算，仍需更多输入及少量 Head 的受控重建检验。上述六条离线比较未新增采集；接续扩展采集与验证见第 11 节。

## 11. 扩展验证：固定 Head 属性与输入依赖

### 11.1 目标与样本

核心问题是：**不同 KV Head 的表示复杂度、特征能量和跨 Head 结构关系，在多大程度上体现固定模型内的 Head 属性，又在多大程度上依赖输入？** 优先检验六条 Pilot 的观察能否延续，再讨论可量化的存储和计算收益。

复用 B1/B2 的 100 条固定输入，仅补采剩余 94 条 V2 表示，不重跑完整 Attention 采集、不覆盖六条 Pilot。模型、BF16/SDPA、全量统计范围、512 位置抽样、448 位置谱/CKA、50 次置换及 Decode 检查点均沿用既有协议。

| 条件 | 已有 Pilot | 扩展已采集 | 联合分析 D |
|---|---:|---:|---|
| RULER 8K / 32K | 各 1 | 各 19，共 38 | 六步轨迹不适用 Δ=32 |
| GovReport 8K / 16K | 各 1 | 各 19，共 38 | 适用，保留实际有效对数 |

### 11.2 四组研究问题与分析口径

**A．Head 表示差异是否跨输入保持，第一优先级。** 主指标为完整中段 K_post/V 的有效秩、平均 Token L2 Norm、E16；E16 仍指中心化协方差前 16 个特征值的方差覆盖率，不是原始坐标前 16 维能量。

对每层计算不同输入间的 Head 排序相关：

$$\rho^{(l)}_{i,j}=\operatorname{Spearman}(X_{i,l,:},X_{j,l,:}).$$

逐层报告相关分布，并区分同条件、跨任务及不同长度条件；继续报告第 10.5 节的固定 Head、输入整层平移及输入×Head 平方和份额，保留绝对值变化。六条 Pilot 的相对 Head 均值作为固定参考，不用新增结果更新，再检查其在剩余输入上的逐层排序、去层均值相关和相对画像 skill。该参考使用测试输入自身层均值，仍不解释为绝对数值预测。对长度影响另用相同 448 位置的 K_post/V 统计作抽样敏感性比较，不混用全量与抽样数值。

**B．RoPE 引起的谱结构变化是否稳定。** 始终在相同 448 个中段位置比较：

$$\Delta r_{eff}=r_{eff}(K_{post})-r_{eff}(K_{pre}),\qquad R_{RoPE}=\frac{r_{eff}(K_{post})}{r_{eff}(K_{pre})}.$$

逐 Layer/Head 报告升秩比例、幅度、秩比及跨输入波动，检查升秩排序和既有例外（零起始 L25/H5、L29/H6）是否延续。例外由 Pilot 提出，不按新增结果事后重选。长度比较优先使用 PG19 同锚点 Pair；GovReport 两长度不配对，只报告条件差异。配对长度输入内容也有变化，不将其差异解释为单独改变 RoPE 位置的因果效应。

**C．跨 Head 表示相关性是否稳定。** 对 K_pre/K_post/V 分别使用每层固定的 28 个无序 Head 对，比较不同输入的 28 维 CKA 排序，而不只比较平均邻居 CKA。保留观测值和超出置换均值的部分，分别检查 Pilot 中较高相似性配对的复现、三种表示的配对排序，以及任务/长度差异。每层输入对相关为 `Spearman(CKA[i,l,28对], CKA[j,l,28对])`；平均邻居指标继续作辅助。稳定的配对相似性是表示结构证据，仍不能直接推导出 Cache 共享或合并。

**D．KV 表示与 Attention 稳定性的关联是否跨样本成立。** 主 RCO 固定为 `prompt_only Page、k=32、Δ=32、rco_raw_mean`，对照完整中段 K_post 有效秩/E16、V 有效秩/E16 和 V 平均邻居 CKA。沿用逐输入先去 Layer 均值再计算 Spearman 的口径，同时保留逐层结果、有效 Head/Step 对数；新增最多 56 条、合并最多 60 条长文本适用，缺失不补零。报告相关大小、方向保持比例及任务差异，不要求强相关。

补充区分固定画像之间的关联与同一 Head 随输入变化的关联：在每个任务/长度条件内，对表示和 RCO 分别去除输入层均值、再减去该条件内各 Head 的跨输入均值，比较两侧剩余响应。它回答“某 Head 相对自身通常水平变化时，RCO 是否同向变化”，属于事后关联，不是预测或因果结论。RULER 不以其他时间间隔替代进入该主分析。

### 11.7 问题 B：RoPE 谱变化的跨输入稳定性

使用六条 Pilot 和新增 94 条既有谱包，在每条输入相同的 **448 个中段位置**比较 K_pre/K_post；不混入全量 K_post。逐输入、Layer、KV Head 保存前后有效秩、差值 Δr 与比值 R，再保存跨输入均值、标准差、范围及升/降秩比例。升秩严格定义为 Δr>0，等值与无效值分别保留；全部 25,600 个组合有效。主要验证集仍为新增 94 条，Pilot 与合并结果单独报告。

**普遍升秩的现象延续。** 新增 94 条有 **23,850/24,064（99.11%）** 的组合升秩；Pilot 为 1,523/1,536（99.15%），合并为 25,373/25,600（99.11%）。对每条输入先平均 Head/Layer，再作六条件等权汇总，平均 Δr 为 **+26.81 [26.68, 26.94]**，平均 R 为 **1.787 [1.781, 1.793]**；这里平均 R 是逐组合秩比的均值，不是总体平均秩之比。95% CI 沿用来源 Bootstrap 2,000 次、seed=20261112，PG19 两长度共用 Pair 抽样，Head/Layer 不作为独立样本。

| L25/H5 | 94/94 | −10.63 | 0.734～0.972 | 加 Pilot 后 100/100 均降秩 |

L29/H6 的反例是 `govreport_8k_004`，有效秩从 35.881 到 37.518，Δr=+1.637、R=1.046。其降秩幅度也随条件变化，PG19 的平均 R 从 8K 的 0.798 降至 32K 的 0.626。全部 256 个坐标中，252 个在新增每条输入上都升秩；另有 L3/H4、L29/H1 分别在 24/94、3/94 条中降秩，属于本轮描述性补充，不据此事后冻结新的 Head 分类。

|---|---:|---:|---:|---:|
| RULER 8K | 19 | +25.87 | 1.732 | 99.22% |

**更长上下文没有带来更大的平均升秩。** 九对新增 PG19 的每对平均 Δr、R 都在 32K 较低；配对长减短为 **Δr −1.047 [−1.455, −0.699]、R −0.0290 [−0.0439, −0.0157]**。加 Pilot 后十对仍均为负，平均差分别约 −1.061/−0.0272。RULER 两条件的平均 Δr 差约 −1.032 [−1.228, −0.836]；GovReport 约 −0.448 [−0.933, +0.041]，当前数据不能明确其平均幅度变化方向。后两者是非配对条件比较；PG19 虽同锚点，输入内容和抽样位置仍随长度变化，均不能解释为只改变 RoPE 位置的因果效应。

结论是：**RoPE 的普遍升秩、相对 Head 响应排序及少数主要降秩例外可跨输入复现，但具体幅度与局部符号仍受任务、长度和输入影响。** 单 Token Norm 近似不变并不要求跨 Token 协方差谱不变，因为不同位置经历不同旋转。该结果仍不证明固定 PCA 方向、可复用压缩变换或收益；相关的 CKA 与 Attention 联合结果见第 11.8～11.9 节。

实现复用既有特征读取、排序、固定参考比较和 Bootstrap；新增 `analysis/rope_stability.py` 与对应脚本入口，本地 19 项相关测试通过。独立重算全部 25,600 个秩变化、15 个子集逐 Head 统计、6,016 个逐层参考相关、316,800 个输入对逐层相关及全部 2,000 次 Bootstrap 汇总，结果一致。数值包约 2.20 MiB，位于 `data/analysis/v2_rope_stability_b_100_20261113_v1/`，保留前后秩、逐 Head 统计、排序、来源抽样和配对差值；原采集和既有分析包未覆盖。本轮仅使用本地 CPU，未新增采集或远程推理。

### 11.8 问题 C：具体 Head 对 CKA 关系的跨输入稳定性

本步只读取六条 Pilot 和新增 94 条已发布的 K_pre/K_post/V Observed、Excess CKA，不重新计算 SVD、CKA 或置换。每层比较完整的 28 个无序 Head 对；Excess 沿用 Observed 减 50 次位置置换均值的定义，不裁剪负值。六条 Pilot 的逐配对平均 CKA 作为固定参考，各表示及 Observed/Excess 分开评估。

高相似配对预先定义为每层 Pilot 均值前 **7 对**，在新增输入中检查 Top-7 保留率，即交集大小/7；边界并列时平分名额，实际数据没有边界并列。随机独立选择两个七对集合的期望保留率为 25%，仅作描述参照。置信区间对每条输入的逐层得分先取均值，再按来源在条件内 Bootstrap 2,000 次、seed=20261112，最后六条件等权。新增 94 条对应 **85 个来源**，PG19 九个 Pair 的两长度共用抽样索引；参考不重采样，不把 Head 对、Layer 或输入对视为独立实验样本。

| 表示 | Observed 对固定参考的排序相关 [95% CI] | Excess 排序相关 [95% CI] | Pilot Top-7 保留率：Observed / Excess |
|---|---:|---:|---:|
| K_pre | 0.974 [0.972, 0.975] | 0.972 [0.971, 0.974] | 90.4% / 90.6% |
| K_post | 0.940 [0.938, 0.941] | 0.932 [0.930, 0.934] | 84.7% / 83.6% |
| V | 0.956 [0.955, 0.958] | 0.958 [0.957, 0.960] | 86.7% / 87.9% |

**具体配对关系能跨输入保持，证据已超出平均邻居 CKA 的稳定性。** 新增输入跨任务两两比较的 Observed 逐层排序相关中位数约为 K_pre 0.971、K_post 0.940、V 0.945；同条件约为 0.991/0.994/0.985。这些输入对分布仅作描述，不计算独立输入对 CI。

**相似性水平和相似配对排序需要分开。** 新增输入的条件等权平均 Observed CKA 为 K_pre 0.709、K_post 0.594、V 0.426，Excess 为 0.656/0.490/0.312；同一输入内 Observed 与 Excess 的配对排序相关均值为 0.993/0.988/0.972。扣除位置置换基线主要降低数值水平，配对次序仍较接近，但不能据此认为共同输入内容的影响已被排除。

| 同一输入内的表示比较 | Observed 配对排序相关 | Excess 配对排序相关 |
|---|---:|---:|
| K_pre 与 K_post | 0.618 | 0.611 |
| K_pre 与 V | 0.411 | 0.343 |
| K_post 与 V | 0.285 | 0.223 |

因此，**各表示内部关系稳定，不代表三种表示共享同一套高相似配对。** 尤其 K_post 与 V 的配对次序差别较大，不能用 Pre-RoPE Key 或 Value 的关系替代实际 Cache Key。

稳定性仍有局部限制。Observed 的最弱层平均参考排序相关约为 K_pre L4 的 0.874、K_post L7 的 0.818、V L29 的 0.867（零起始）；K_post L12 的 Top-7 保留率均值仅约 0.625。每种表示的 224 个 Pilot 高相似 Layer×Head 对中，分别有 128/114/126 个在全部 94 条上保留，但少数配对复现很弱，例如 K_pre L0 的 H1–H2 仅在 5/94 条中保留，其 Pilot 排名恰为第 7。不能将较高的总体相关解释为每条边或 Top-7 边界固定。

长度影响对 K_post 更明显：九对新增 PG19 的逐层配对排序相关中位数，Observed 为 K_pre 0.984、K_post 0.895、V 0.982，Excess 为 0.984/0.884/0.982。K_post 对 Pilot 的 Observed 参考相关均值在 PG19 8K/32K 为 0.953/0.906，在 RULER 8K/32K 为 0.957/0.913；任务与长度会改变部分关系。PG19 按来源成组，其他条件不伪造配对；仍不能把长度条件差异解释为 RoPE 位置的单因素效应。

结论是：当前模型和任务范围内，**跨 Head 的表示相似关系具有可复现的结构，K_pre 最稳定，K_post 对条件变化更敏感；不同表示需要分别建模。** 这加强了结构相关性的证据，仍不等于可共享/合并 Cache、具有固定对齐变换或能带来压缩收益；其与 Attention 稳定性的联合结果见第 11.9 节。

三种表示分别输出每层 8×8 的 Observed/Excess 对称矩阵，含 Pilot、条件等权的新增/合并结果及六个任务/长度条件，保留均值、标准差、有效输入数、Top-7 频率和固定参考选择；对角线未测量，保持 NaN。入口 `scripts/analyze_cka_stability.py`，数值包位于 `data/analysis/v2_cka_stability_c_100_20261113_v1/`，约 **8.15 MiB**。复用既有读取、排序、参考比较和 Bootstrap，仅扩展特征读取函数以支持 Head 对坐标，既有 Head 读取默认行为不变。

本地 **22 项相关测试通过**，含禁止调用 SVD/谱/CKA 计算、矩阵对称性、并列/无效处理、来源成组及原包不改写。独立核验全部 537,600 个发布值、18,048 个逐层参考相关及 Top-7 保留率、950,400 个输入对逐层相关、28,800 个同输入表示比较、全部矩阵与 2,000 次来源 Bootstrap，结果一致。本轮仅用本地 CPU，未新增采集，旧结果保留。

### 11.9 问题 D：Attention 与 KV 的联合分析

**数据与口径。** 全部 100 条 V2 与已核验 B2 完成包内的 B1 Page RCO 副本按样本、零起始 Layer、物理 KV Head 对齐；V2 保存的 RCO 及有效 Step 对数逐项与该副本相等。主指标固定为 `prompt_only Page、k=32、Δ=32、rco_raw_mean`，使用 B1 原完整轨迹，每 Head 有效 Step 对数为 429～991，不以 V2 回放长度替代。RULER 40 条只有六步轨迹，不参加该长期关系；适用 60 条长文本，新增 **56 条、47 个来源**为主要验证集，四条 Pilot 及合并 60 条分别保留。

五项主特征仍为完整中段 K_post/V 有效秩、E16 与 V 邻居平均 Observed CKA。沿用此前 14 项 FP64 关联特征，另读已保存的两个平均 Norm 作补充，共 16 项，不重算谱、CKA 或 RCO。统计按输入来源进行，四个有效条件等权；Bootstrap 2,000 次、seed=20261112，PG19 两长度共用来源抽样。Head、Layer、邻居及 Step 对不作为独立实验样本，CI 为逐项描述，未作多重比较校正。

**D1：跨输入、跨任务的关联复现。** 每条输入在共同有效坐标上分别去除两侧 Layer 内 Head 均值，再对 256 个坐标计算 Spearman，保留逐层结果和有效数。下表为新增输入的逐条件均值；五项主特征在全部 56 条中都保持了对应 Pilot 的方向。

| 条件 | K_post 有效秩 | K_post E16 | V 有效秩 | V E16 | V CKA |
|---|---:|---:|---:|---:|---:|
| GovReport 8K，19 条 | +0.176 | −0.291 | −0.138 | +0.126 | −0.298 |
| GovReport 16K，19 条 | +0.179 | −0.303 | −0.111 | +0.099 | −0.318 |
| PG19 8K，9 条 | +0.097 | −0.154 | −0.196 | +0.199 | −0.339 |
| PG19 32K，9 条 | +0.097 | −0.143 | −0.184 | +0.189 | −0.340 |

因此，**两个长文本任务中的方向一致，但强度不同**：Key 秩/E16 的联系在 GovReport 较强，Value 秩/E16 在 PG19 较强；V CKA 的负相关较一致。条件等权的五项平均相关分别为 +0.137、−0.223、−0.157、+0.153、−0.324，95% CI 均不跨零。这不意味着相关性很强，也不支持统一的“更稳定就更低秩”规则。

任务限制在补充特征中更明显。K_post 邻居 CKA 在 GovReport 的相关约 −0.36，在 PG19 约 −0.10～−0.14：新增数据说明 PG19 也有较弱负相关，不能继续概括为只在 GovReport 成立。K_pre 邻居 Excess CKA 在 GovReport 约 −0.17～−0.20，在 PG19 仅约 −0.016～−0.024，后者区间跨零、个体方向混合，未支持同样可靠的跨任务关系。同 448 位置的 K_pre 秩仍负相关，K_post 秩正相关，不能互相替代。

**D2：固定 Head 关联与输入响应分开。** 在每个任务/长度条件 c 内，对 X 及 RCO 分别定义：

$$z_{i,l,h}=X_{i,l,h}-\overline X_{i,l,:},\qquad a_{c,l,h}=\operatorname{mean}_{i\in c}z_{i,l,h},\qquad e_{i,l,h}=z_{i,l,h}-a_{c,l,h}.$$

比较两侧固定画像 a 的 Spearman，以及残差 e 的整体相关、逐输入相关及逐 Head 跨输入相关。这里 a 在当前条件内估计，用于描述性分解，区别于 A/C 的固定 Pilot 参考；每次 Bootstrap 均重新估计 a，不能固定原均值后只重抽残差得分。点估计与 Bootstrap 使用相同的稳定去均值路径：先减参考 Head、再减参考输入后累积，避免大偏置、并列值和重复抽样引入虚假非零响应；无变化时相关保留无效。

| 主特征 | 固定画像相关，条件等权 | 逐输入残差相关均值 [95% CI] |
|---|---:|---:|
| K_post 有效秩 | +0.144 | +0.008 [−0.065, +0.081] |
| K_post E16 | −0.232 | −0.042 [−0.112, +0.024] |
| V 有效秩 | −0.170 | +0.056 [−0.016, +0.118] |
| V E16 | +0.167 | −0.058 [−0.120, +0.016] |
| V 邻居 Observed CKA | −0.336 | +0.001 [−0.039, +0.040] |

**固定画像之间的关联保留，输入残差关联明显较弱。** 五项主特征的整体残差相关也仅约 −0.064～+0.061，条件等权 CI 均包含零；全部 16 项特征的条件等权残差 CI 也均包含零。这不是证明输入响应独立或永远没有作用，而是当前数据未提供同样清晰、跨条件可靠的残差关联证据。

仍需保留条件局部现象：GovReport 8K 中，V 有效秩的平均残差相关为 **+0.071 [+0.005, +0.145]**，V E16 为 **−0.075 [−0.150, −0.004]**，与固定画像之间的方向相反；其他条件中两者点估计也分别为正/负，但区间跨零。不能把“不同 Head 之间，V 秩低的更稳定”改写成“同一个 Head 在某输入上秩降低时一定更稳定”，也不能将这两个未经多重比较校正的局部弱信号当成已确认的任务专属规律。

条件内去除输入 Layer 平移后，K_post 秩/E16 的相对固定 Head 平方和份额约 **98.2%～99.3%**，V 秩/E16 约 **96.2%～96.9%**，V Observed CKA 约 **97.6%～98.3%**，两个 Norm 约 **98.1%～99.6%**；RCO 自身约 **92.3%～95.9%**。因此这些指标主要体现固定 Head 的相对差异，但仍存在非零输入响应，其中 V 秩/E16 的相对响应比 K_post 更大。这些是按条件计算的描述性平方和，不能当作总体方差、D1 相关性的解释百分比，也不能与 A 混合条件的份额直接等同。加入四条 Pilot 后，主要判断保持，接近零的局部系数仍可能换号。

本轮支持的研究认识是：**Head 之间较稳定的表示差异，与较稳定的 Attention 行为存在可复现联系；同一 Head 随输入变化的联系则较弱、依赖条件，且可能反向。** 固定 Head 画像可以作为后续受控重建的候选先验，当前结果不足以推出按单次输入动态调节压缩预算的规则，也未验证因果性、固定子空间或存储/计算收益。

实现为 `analysis/attention_kv_joint.py` 与脚本入口，复用既有相关、平方和分解及来源 Bootstrap。**35 项相关测试通过**，覆盖固定/响应反向、缺失坐标、退化抽样、重估均值、RCO 错位拒绝及旧结果保留；D1 与此前 840 个逐输入、26,880 个逐层系数完全一致。独立核验 100 条来源、960 个有效逐输入相关、30,720 个逐层相关、八组 D2 分解、全部 CI/条件汇总及 84 次抽样重拟合，均通过。结果包约 **13.17 MiB**，位于 `data/analysis/v2_attention_kv_joint_d_100_20261113_v1/`，保留全部坐标、原特征、RCO/有效数、分解与 2,000 次 Bootstrap 数值；仅用本地 CPU，原数据和 A/B/C 包保持不变。

## 12. A～D 联合研究结论

本轮已完成从六条 Pilot 到新增 94 条的扩展分析，B/C/D 均不再是“待分析”。A～C 的主验证覆盖新增 **94 条、85 个来源**；D 的长期 Page RCO 只适用其中 **56 条、47 个来源**，不包含 RULER。四项复用同一模型及同一批固定输入，是互补的观察角度，不是四次独立实验；PG19 两长度按来源成组。

| 维度 | 研究问题 | 当前判断与关键证据 | 保留的限制 |
|---|---|---|---|
| A | Head 表示画像是否跨输入稳定？ | **相对画像获得较强支持。** 秩、E16、Norm 对固定 Pilot 的逐层排序相关均值为 0.916～0.966。 | 绝对值仍随输入平移，存在较弱层；排序稳定不证明 PCA 方向固定。 |
| B | RoPE 对 Key 的影响是否跨输入稳定？ | **普遍升秩及相对响应排序获得支持。** 新增组合约 99.11% 升秩，Δr/R 的参考排序相关为 0.895/0.908。 | 幅度依赖任务与长度；L25/H5 在 100 条均降秩，L29/H6 有一条升秩反例，不能概括为全部同向。 |
| C | 具体 Head 对的表示相似性是否跨输入稳定？ | **配对结构获得较强支持。** K_pre/K_post/V 的 Observed 参考排序相关为 0.974/0.940/0.956，Pilot Top-7 保留率为 90.4%/84.7%/86.7%；Excess 保持主要趋势。 | 三种表示的高相似配对不同；部分层和边界配对不稳，CKA 不直接证明 Cache 可共享。 |
| D | KV 表示与 Attention 稳定性是否存在可重复联系？ | **固定 Head 画像间的联系得到支持。** D1 五项主关系在全部 56 条新增长文本中保持 Pilot 方向；D2 固定画像关联延续。 | 同一 Head 的输入残差联系较弱，五项均值约 −0.058～+0.056、总体 CI 均跨零；局部可反向，尚无可靠的通用动态规则。 |

联合结果支持核心假设的描述性部分：**不同 KV Head 具有可跨输入复现的表示统计和配对结构，这些差异与 Attention 时间行为存在可重复联系。** A 表明相对画像可以复现，B/C 进一步表明这种结构需要区分 RoPE 前后及 Key/Value，D 则把表示结构与既有 Attention 观察联系起来。它们共同支持把固定 Head 画像作为候选先验，但没有确定这些联系的因果机制。

这里需要区分三件事。第一，相对画像稳定不代表绝对数值或每个 Layer/Head 的行为固定，V 的输入平移和局部响应仍存在。第二，K_pre、K_post、V 不能互相替代：RoPE 改变跨 Token 谱和配对结构，D 中 K_post 与 V 的秩关联方向也不同，不能形成“越稳定就统一越低秩”的规则。第三，**不同 Head 之间的规律不等于同一 Head 随输入变化的规律**；D2 中联系减弱及局部反向，限制了从 D1 直接推导输入自适应预算的做法，区间跨零也不等于已经证明两者独立。

V2 因而完成了当前模型内的观察性问题验证，尚未完成压缩方案验证。有效秩、E16 和 CKA 稳定不证明固定子空间、对齐变换或 KV 共享可用；现有结果也不包含压缩后质量、含元数据的存储字节、显存或速度收益。A 的相对参考评估使用目标输入层均值，D2 的画像在条件内估计，均不能解释为部署预测；全部输入此前用于 B1/B2，结论仍限于当前模型和任务/长度范围内的内部扩展。

下一研究目标应是检验这些固定先验是否有实际用途：优先小规模比较固定 Head 子空间或预算与统一基线，在相同字节预算下检查重建及 Attention 功能误差，再决定是否开展模型质量和真实资源测试。该方向是基于本轮结果的建议，具体方案和实施目标尚未确定，本轮不启动新采集或压缩实验。
