# HeadKV 研究总览

更新于 2026-11-11。数据准备、V1-B1、V1-B2 及基于已有数值的探索性留出分析均已完成。

## 1. 项目来源与目标

技术来源为 **NVIDIA KVPress → KV-Base → HeadKV**。KV-Base 提供模型生成、KV Cache、
Prefill/Decode 生命周期和观测基础设施；本项目的专用代码位于
`experiments/head_analysis/`，首先研究不同 Head 的 Attention 访问行为。

整体目标是研究三个问题：不同 Head 的分布是否存在差异；这些差异在时间、输入和任务间
是否稳定；不同分布特征之间是否存在可解释的关系。

V1 参考 CateKV 的跨 Query 一致性和 FlexiCache 的 Page 时间稳定性，统一模型、输入和
生成轨迹后比较二者。关注论文中的现象及指标，不要求完整复现其压缩或系统方案。
KV 张量本身的数值分布、有效秩和跨 Head 表示冗余尚未开展。

## 3. 共用实验设置

模型为 NousResearch/Meta-Llama-3.1-8B-Instruct，32 层，每层 32 个 Query Head、
8 个 KV Head，GQA 每组 4 个 Query Head。采集使用 BF16、SDPA、Batch=1、完整无压缩
KV Cache。B1 使用 Greedy 生成；B2 回放 B1 的生成 Token。

输入为 RULER 8K/32K 各 20 条、GovReport 8K/16K 各 20 条、PG19 8K/32K 各 10 条。
PG19 两个长度共享十个续写锚点；GovReport 两个长度不作内容配对。

在线仅保留基础统计和紧凑轨迹，离线进行汇总、关联与 Bootstrap，不常规保存完整
Attention 矩阵。离线分析无需 GPU，也无需再次运行模型。

## 4. 当前结论与开放问题

现有结果支持：固定模型中不同 Head 的时间行为具有结构性差异；Prefill 频次集中程度
包含与 Decode 时间稳定性相关的信号。集合覆盖、注意力集中程度和时间稳定性应分别研究，
目前不存在一个已经验证的通用“好 Head”分数。

上述结论限于当前模型、固定输入和生成轨迹。已对这 100 条做探索性留出比较，但尚未
使用独立新输入验证，也未开展跨模型、多变量控制、因果干预或压缩质量/系统效率实验；
尚未冻结 Stable/Unstable 等二值分类。

下一步拟验证：不同 KV Head 的 Attention 稳定差异，是否对应其 K/V 数值分布、特征能量、
有效秩和跨 Head 表示相关性的差异。[V2 方案](v2_kv_representation.md)以六条 Pilot 起步，
明确 Pre/Post-RoPE 采集范围、全层 CKA 和资源预算；采集、落盘及固定输入回放已在小模型验证，真实模型试运行及分析待推进。
Prefill 信号在独立新输入上的表现，以及固定区域与中段访问的关系，仍是可选研究问题。

研究报告。研究报告保留样本数、关键参数、主要效应及必要置信区间，确保结论可理解。
